# AGENTS.md

The miniz_oxide library is used by the rust compiler (indirectly via the backtrace library) and thus acceptance of LLM use will never exceed what is accepted in the [rust project LLM guidelines](https://forge.rust-lang.org/policies/llm-usage.html).

As of now, due to the many ethical and legal concerns with LLM use this project will also not accept any LLM generated code changes beyond completely trivial changes and test cases.
